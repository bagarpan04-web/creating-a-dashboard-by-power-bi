# 📱 Mobile Sales Dashboard | Power BI

## 📌 Project Overview

This project is an interactive *Mobile Sales Dashboard developed using Microsoft Power BI*.

The dashboard provides a comprehensive view of mobile sales performance by analyzing *total sales, transactions, quantity sold, mobile models, brands, cities, payment methods, customer ratings, day-wise sales, and monthly performance*.

The project also includes *MTD (Month-to-Date) reporting and Same Period Last Year comparisons* to help analyze sales performance over time.

---

## 🎯 Project Objectives

The main objectives of this dashboard are to:

* Monitor overall mobile sales performance.
* Analyze sales by city.
* Compare sales performance across mobile brands.
* Identify top-performing mobile models.
* Analyze monthly quantity trends.
* Understand customer payment preferences.
* Analyze customer rating status.
* Compare sales performance by day of the week.
* Track Month-to-Date (MTD) performance.
* Compare current sales with the same period last year.
